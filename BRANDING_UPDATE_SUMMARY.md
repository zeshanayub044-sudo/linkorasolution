# LINKORA SOLUTIONS branding update

- The public pages (`index.html`, `about.html`, `services.html`, `blog.html`, and `contact.html`) now use the new lion-and-L artwork in their headers, footers, metadata, and opening animation. The shared footer built by `script.js` uses the same mark. The Tennis Portal and staff attendance page use it in their own brand lockups.
- `assets/linkora-logo.png` is the original logo supplied by the owner. `assets/linkora-mark.png` is a deterministic square crop of its L, lion, and blue sun. The previous `assets/linkora-icon.png` was removed.
- `assets/favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png`, `android-chrome-192x192.png`, and `android-chrome-512x512.png` were regenerated from that same crop. `site.webmanifest` uses the new app icons and brand name. Run `tools/generate-brand-assets.ps1` to regenerate the icon set from the committed source image.
- `intro-init.js` and `styles.css` create a roughly 2.9-second opening sequence: **LINK** enters from the left, **ORA** enters from the right, the full official logo appears, and the overlay fades away. It plays once per browser session across the public pages. Reduced-motion visitors skip it. CSS and JavaScript both release the overlay if an animation event is missed.
- The full original image is referenced as the public pages' social-share image. Versioned icon, stylesheet, and script URLs make existing browsers pick up the changed branding. The small header mark is served at 128 pixels to avoid loading a full-size image for a 50-pixel display.
- Existing navigation, forms, and portal sign-in logic were left in place. A narrow-screen header adjustment keeps the longer official brand name readable; the WhatsApp call to action remains in the homepage hero on phones.
